## 치트·편의 기능

아래 버튼은 게임보이 버튼 기준입니다. 조합키는 **START를 먼저 누른 채 A 또는 SELECT를 추가로 누르는 방식**을 권장합니다.

| 조작 | 기능 |
|---|---|
| START+A | 현재 파티 HP·SP 최대 회복, 전투불능 무장 부활 |
| SELECT+START | 치트 메뉴 열기 |
| 메뉴에서 ↑↓ / ←→ / B | 항목 이동 / 값 변경·끝값 순환 / 닫기 |
| 필드에서 B를 누른 채 방향키 | 약 1.5배 이동 처리로 대시 |
| SELECT+A | 사운드 테스트(16곡, 타이틀 복귀 항목 포함) |

| 치트 항목 | 선택값·효과 |
|---|---|
| 경험치 | 1·10·20·30배. 전투 경험치 안내와 실제 분배에 적용 |
| 공격력 | 1·10·20·30배. 아군 일반 무장전투의 무기 공격 피해에 적용 |
| 전투 후 회복 | 끔/켬. 일반 전투 승리·정상 퇴각 후 파티 회복·부활 |
| 인카운터 | 끔/켬. 무작위 조우를 조절하며 고정 이벤트 전투는 유지 |

치트 설정은 두 게임 저장 슬롯에 공통으로 보관됩니다. 설정 보존은 진행 상황 자동 저장과 별개입니다. 공격력 배율은 비책·병사전투·일기토 등 별도 전투 계통에는 적용하지 않습니다. **적벽 후반의 진행 이벤트 이후에는 인카운터가 켬으로 고정**되며, 진행을 위해 끌 수 없습니다. 즉시 회복은 공격 연출·전멸 확정 등 일부 상태에서 제한됩니다.

1. 압축을 푼 무수정 원본의 크기·MD5·CRC32 또는 SHA-256이 위 표와 일치하는지 확인합니다.
2. 아래 해당 패치를 원본에 **한 번만** 적용하고 결과를 별도 파일로 저장합니다.
3. 적용 후 결과 크기와 체크섬을 다음 표와 대조합니다.
