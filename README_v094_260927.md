# 천지를 먹다 GB v0.9.4 — 사운드 테스트 문구 수정

## 변경 내용

- 제목음악 → **타이틀**
- 마을가·마을나·마을다 → **마을 가·마을 나·마을 다**
- 전투가·전투나 → **전투 가·전투 나**

v0.9.3의 타이틀 애니메이션, 기존 한글화와 출력 속도 개선을 포함합니다.

## 적용 방법

**수정하지 않은 일본판 원본에 이번 패치 한 번만 적용합니다.**

- 입력 ROM: `Tenchi o Kurau (Japan).gb` (262,144바이트)
- 입력 SHA-256: `2884676b3bb261204f480767ba716dfc5266e536b7628fc73f9243c1e0efa8c7`
- 패치: `GB_Tenchi_KR_v094_260927_from_Japan.xdelta`
- 결과 ROM SHA-256: `ef347b089f9bc8af23592ee6633c75cf10df08b8c7c0c92a2e531e902e1d355d`

```text
xdelta3 -d -s "Tenchi o Kurau (Japan).gb" "GB_Tenchi_KR_v094_260927_from_Japan.xdelta" "GB_Tenchi_KR_v094_260927.gb"
```

기존 저장 파일은 백업한 뒤 새 ROM과 같은 기본 이름으로 복사하고, 게임 내 이어하기로 불러옵니다.

## 확인 범위

자체 CPU/PPU 실행 프로브에서 SELECT+A 진입, 첫 화면의 타이틀 표시, 16곡 순환과 타이틀 복귀, 나가기, 필드 메뉴 8단계의 기존 화면·VRAM 일치를 확인했습니다. 실행 화면에서 변경한 여섯 곡명의 글자와 띄어쓰기를 확인했습니다. 독립 에뮬레이터·실기·음원 재검사는 하지 않았습니다.

일본판 원본에 패치를 적용한 결과가 최종 ROM과 바이트 단위로 일치합니다. 빌더는 일본판 원본과 해시가 고정된 기존 누적 패치를 입력으로 사용하며, 배포 패치는 일본판 원본만을 기준으로 생성합니다.

프로젝트 루트에서 재현: `python work/developer/build_sound_v094.py`

기록: `reports/sound_v094.json`
